cc-frame-viewer is a viewer of traces captured from Chrome with
--trace-all-rendered-frames.

QuickStart
========

**Make sure to git submodule update --init after cloning**

./cc-frame-viewer unittest_data/example.json

Dependencies
==========
- python2.6 or better
- chrome [yes, chrome]
