# //media/gfx

This directory contains client-side graphics, SharedImage, canvas, and
compositor presentation utilities for `//media`.

Unlike `//media/gpu` (which contains code that executes inside the GPU
process), `//media/gfx` provides client-side helper classes and utilities that
interoperate with GPU, Viz, Skia, and CC components.
