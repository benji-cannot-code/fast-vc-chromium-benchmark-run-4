# AIM Eligibility Debug UI

This directory contains the Debug UI for AIM Eligibility.

## Usage

- Navigate to `chrome://omnibox/aim-eligibility/`
- View eligibility and observe changes.
- Make on-demand server eligibility requests.
- Hardcode server eligibility response.
