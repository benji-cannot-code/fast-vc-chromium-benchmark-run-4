# Unexportable Keys Internals

This directory contains a Debug UI for unexportable keys implementation on a
given platform. The only supported platform as for now is MacOS. To access the
page, make sure you run Chrome with `--enable-features=UnexportableKeyDeletion`
and navigate to `chrome://unexportable-keys-internals`.
